Package installation is your responsibility. After installing DialogR, install the required R packages. They are separate from the application.

  1. Download and install the appropriate application release.
  2. Start DialogR and make sure its local R runtime is available. If no R installation is found, install R and select it in the application’s runtime settings.
  3. Choose Packages → Install required R packages. Wait for installation to finish and resolve any reported failures.
  4. Use Packages → Update development versions when a required package is too old.
  5. Import a dataset and follow the first-analysis guide.

Browser / WebR

Ready when you are.

WebR runs R in your browser. The packages needed for DialogR’s supported dialogs are included in its supplied library; you do not need to install them on your computer.

WebR is slower than local R. Startup includes loading the runtime and package library. Imports and analyses can also take longer.

Begin with a modest dataset and allow loading to finish. Use the file picker to bring data into the browser session, and save the files and results you need before closing it.
