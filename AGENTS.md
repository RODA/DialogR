# Dialog authoring

- Dialogs must not contain explanatory text. Keep them limited to controls and concise labels.
- Put explanations, usage guidance, and descriptions of options in the manual.
- Use concise labels and omit words already implied by the dialog's purpose (for example, "Recode missing values", not "Recode missing values for the destination").
- Design for translation: allow labels to wrap and leave enough space for longer wording in other languages. Do not assume English labels will remain on one line.
- Present mutually exclusive sets of options as compact panes or tabs. Each pane must arrange its controls from the top of the available space; hiding another pane must not leave gaps between the visible controls.
- Size the dialog for the largest active pane, not for all panes stacked vertically. Keep shared controls in consistent positions.
